**Original:** API tokens authenticate external requests to the Strapi Content API without exposing user credentials. Each token is scoped to a set of permissions and expires after a configurable duration.

**中文译文:** API tokens 用于验证外部 client 对 Strapi Content API 的请求，无需暴露用户 credentials。每个 token 都有明确 permissions scope，并会在可配置的 duration 后过期。

**Original:** API tokens allow external clients to authenticate requests to the Strapi Content API. For programmatic access to the Admin panel features, see Admin Tokens.

**中文译文:** API tokens 允许外部 client 对 Strapi [Content API](/cms/api/content-api) 请求进行 authentication。若要程序化访问 Admin panel 功能，请使用 [Admin Tokens](/cms/features/admin-tokens)。

**Original:** API tokens and Admin tokens are strictly separated: a Content API token is rejected on admin routes, and an admin token is rejected on Content API routes.

**中文译文:** API tokens 与 Admin tokens 严格隔离：Content API token 在 admin routes 上会被拒绝，Admin token 在 Content API routes 上也会被拒绝。

**Original:** Prefer read-only tokens for public access, scope tokens to only what you need, rotate long-lived tokens, and store them in a secrets manager.

**中文译文:** 对公开访问优先使用 read-only token；只授予实际需要的权限；长期 token 应定期 rotate；并将 token 存放在 secrets manager 中。

**Original:** Plan: Free feature. Role & permission: Minimum "Access the API tokens settings page" in Roles > Settings - API tokens. Activation: Available by default. Environment: Available in both Development & Production environment.

**中文译文:** 功能属性：Free feature；最低需要 *Roles > Settings - API tokens* 中的 “Access the API tokens settings page” permission；默认可用；Development 与 Production environment 均支持。

## Configuration

**Original:** Most configuration options for API tokens are available in the admin panel, and your Strapi project's code can be used to alter how API tokens are generated.

**中文译文:** API tokens 的大多数配置都可以在 admin panel 中完成，也可以通过 Strapi 项目代码调整 API token 的生成方式。

### Admin panel settings

**Original:** Path to configure the feature: Settings > Global settings > API Tokens.

**中文译文:** 配置路径：*Settings > Global settings > API Tokens*。

**Original:** The API Tokens interface displays a table listing all created content-api tokens. From there, you can edit a token's name, description, type, duration or regenerate the token, and delete a token.

**中文译文:** *API Tokens* 界面会以表格列出所有已创建的 content-api tokens。可以在这里编辑 token 的 name、description、type、duration，执行 regenerate，或删除 token。

**Original:** Strapi pre-generates 2 API tokens for you, a Full access one and a Read-only one. Since tokens can be only seen once without encryption configured, you may want to regenerate them after setting up an encryption key to make them permanently viewable.

**中文译文:** Strapi 会预生成 2 个 API tokens：一个 Full access，一个 Read-only。若未配置 encryption，token 默认只显示一次；因此可先设置 encryption key，再 regenerate 这些 token，使其在 admin panel 中持续可见。

#### Creating a new API token

**Original:** 1. Click **Create new API Token**.
2. Configure:

| Setting name | Instructions |
| --- | --- |
| Name | Write the name of the API token. |
| Description | (optional) Write a description. |
| Token duration | Choose 7 days, 30 days, 90 days, or Unlimited. |
| Token type | Choose Read-only, Full access, or Custom. |

3. For Custom tokens, define permissions for API endpoints using checkboxes.
4. Click **Save**. The token is shown at the top with a copy button.

**中文译文:** 1. 点击 **Create new API Token**。
2. 配置：

| 设置项 | 说明 |
| --- | --- |
| Name | 输入 API token 名称。 |
| Description | （可选）输入描述。 |
| Token duration | 选择 7 days、30 days、90 days 或 Unlimited。 |
| Token type | 选择 Read-only、Full access 或 Custom。 |

3. 对 Custom token，可按 content-type 设置 API endpoints permissions，并使用 checkbox 启用或禁用。
4. 点击 **Save**。新 token 会显示在界面顶部，并提供 copy 按钮。

**Original:** If an encryption key is configured in your Strapi project (`admin.secrets.encryptionKey`), newly created and regenerated API tokens are viewable at any time. Without an encryption key, tokens are viewable only once after creation or regeneration.

**中文译文:** 如果 Strapi 项目配置了 encryption key（`admin.secrets.encryptionKey`），新创建和 regenerated API tokens 可以随时在 admin panel 中查看。未配置 encryption key 时，token 只会在创建或 regeneration 后显示一次。

#### Regenerating an API token

**Original:** 1. Click the API token's edit button.
2. Click **Regenerate**.
3. Confirm by clicking **Regenerate** in the dialog.
4. Copy the new API token shown at the top.

**中文译文:** 1. 点击 API token 的 edit 按钮；
2. 点击 **Regenerate**；
3. 在 dialog 中再次点击 **Regenerate** 确认；
4. 复制顶部显示的新 API token。

### Code-based configuration

**Original:** New API tokens are generated using a salt. This salt is automatically generated by Strapi and stored in environment variables (the `.env` file) as `API_TOKEN_SALT`.

**中文译文:** 新 API token 生成时会使用 salt。Strapi 会自动生成该 salt，并通过 `.env` 中的 `API_TOKEN_SALT` environment variable 保存。

**Original:** The salt can be customized either by updating `apiToken.salt` in the `/config/admin` file or by creating an `API_TOKEN_SALT` environment variable.

**中文译文:** 可以通过以下方式自定义 salt：修改 `/config/admin` 中的 `apiToken.salt`，或者在项目 `.env` 中创建 `API_TOKEN_SALT` environment variable。

**Original:** Changing the salt invalidates all existing API tokens.

**中文译文:** 修改 salt 会使所有现有 API tokens 失效。

#### Ensuring API tokens are visible in the admin panel

**Original:** To allow persistent visibility of API tokens in the admin panel, an encryption key must be provided under `secrets.encryptionKey` in `/config/admin`.

**中文译文:** 要让 API tokens 在 admin panel 中持续可见，需要在 `/config/admin` 的 `secrets.encryptionKey` 中配置 encryption key。

**Original code (kept unchanged):**

```js title="/config/admin.js"
module.exports = ({ env }) => ({
  // other config parameters
  secrets: {
    encryptionKey: env('ENCRYPTION_KEY'),
  }
});
```

```ts title="/config/admin.ts"
export default ({ env }) => ({
  // other config parameters
  secrets: {
    encryptionKey: env('ENCRYPTION_KEY'),
  }
});
```

**中文译文:** JavaScript 与 TypeScript 示例代码保持原样。该 key 用于 encrypt / decrypt token values。没有这个 key 时，token 仍可使用，但初次显示后将无法再次查看。新 Strapi 项目会自动生成该 key。

**Original:** For automation workflows that need to call Admin panel features programmatically, use admin tokens instead.

**中文译文:** 如果自动化工作流需要程序化调用 Admin panel 功能，请改用 [Admin Tokens](/cms/features/admin-tokens)。

## Usage

**Original:** Using API tokens allows executing a request on REST API or GraphQL API endpoints as an authenticated user.

**中文译文:** 使用 API tokens，可以以 authenticated user 身份请求 [REST API](/cms/api/rest) 或 [GraphQL API](/cms/api/graphql) endpoints。

**Original:** API tokens can be helpful to give access to people or applications without managing a user account or changing anything in the Users & Permissions plugin.

**中文译文:** API tokens 可以在无需管理 user account、也无需修改 Users & Permissions plugin 的情况下，为人员或应用提供 API 访问能力。

**Original:** When performing a request to Strapi's REST API, the API token should be added to the request's `Authorization` header with the syntax `bearer your-api-token`.

**中文译文:** 请求 Strapi REST API 时，应将 API token 加入 request 的 `Authorization` header，格式为 `bearer your-api-token`。

**Original:** Read-only API tokens can only access the `find` and `findOne` functions.

**中文译文:** Read-only API tokens 只能访问 `find` 和 `findOne` functions。
