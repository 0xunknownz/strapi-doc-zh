**Original:** What is Strapi Cloud?

**中文译文:** 什么是 Strapi Cloud？

**Original:** Strapi Cloud is a hosting platform that allows you to deploy your Strapi applications. It is a fully managed content platform built on top of Strapi, the open-source headless CMS.

**中文译文:** Strapi Cloud 是一个用于部署 Strapi 应用的托管平台。它构建在开源无头 CMS Strapi 之上，是一套全托管的内容平台。

**Original:** **🤝 Why Strapi Cloud?** Strapi Cloud enables you to increase your content velocity without having to compromise on customization needs and requirements.

**中文译文:** **🤝 为什么选择 Strapi Cloud？** Strapi Cloud 可以帮助你提升内容交付效率，同时无需牺牲业务对自定义能力的需求。

**Original:** Development teams can rely on Strapi Cloud to abstract away the complexity of infrastructure management while keeping your development workflow and extending the core capabilities of Strapi.

**中文译文:** 开发团队可以借助 Strapi Cloud 屏蔽基础设施管理的复杂度，同时保留既有开发工作流，并继续扩展 Strapi 的核心能力。

**Original:** Content managers can use Strapi Cloud to autonomously manage all types of content and benefit from a complete set of content collaboration, security, and compliance features.

**中文译文:** 内容管理人员可以使用 Strapi Cloud 自主管理各种类型的内容，并获得完整的内容协作、安全与合规能力。

**Original:** The typical workflow, which is recommended by the Strapi team, is:

**中文译文:** Strapi 团队推荐的典型工作流如下：

**Original:**
1. Create your Strapi application locally (v4.8.2 or later).
2. Optionally, extend the application with plugins or custom code.
3. Version the application's codebase through your git provider (GitHub or GitLab).
4. Deploy the application with Strapi Cloud.

**中文译文:**
1. 在本地创建 Strapi 应用（`v4.8.2` 或更高版本）。
2. 根据需要，通过插件或自定义代码扩展应用。
3. 通过 Git 提供商（GitHub 或 GitLab）对应用代码库进行版本管理。
4. 使用 Strapi Cloud 部署应用。
