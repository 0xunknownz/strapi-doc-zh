## 翻译原则

1. 产品名、框架名、库名、协议名和缩写保留英文。
2. Strapi UI 功能名称优先保留官方英文。
3. 命令、文件名、环境变量、API 路径和代码保持原样。
4. 中文与英文、数字之间保留一个半角空格。
5. 译文采用自然、专业的中文技术文档表达。

详见 `TRANSLATION_GUIDE.md` 与 `GLOSSARY.md`。
